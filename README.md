# ForeverCraft

ForeverCraft extends the professions window in WoW Forever with crafting plans, an inventory-aware shopping and farming list, a disenchanting queue, and one-key fishing with a catch journal.

## Installation

Download the installable ZIP from [GitHub Releases](https://github.com/Retronimrod/ForeverCraft/releases). Extract the `ForeverCraft` folder into the WoW Forever client's `Interface/AddOns` directory, then start the game or run `/reload`.

Use `/forevercraft` for settings and `/fclist` for the shopping list. [LibProfessionDB](https://www.curseforge.com/wow/addons/libprofessiondb) is optional and recommended for updated skill thresholds.

Built for **WoW Forever**, interface 16001.
