# ForeverCraft v0.1.114-alpha

First public test build for WoW Forever.

- Inventory-aware crafting plans and a combined shopping and farming list.
- Vendor and Auction House shortcuts for missing materials.
- Disenchanting queue, one-key fishing, and a fishing journal.
- Seven-day crafting and skill history in the professions overview.
- Optional LibProfessionDB integration for current Forever skill thresholds, with a bundled fallback.

Download the ForeverCraft ZIP, extract its folder into Interface/AddOns and restart the game or run /reload.
